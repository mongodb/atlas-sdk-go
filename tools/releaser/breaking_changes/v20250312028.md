# Breaking Changes

## SDK changes

### incompatible changes

- (*GroupAlertsConfig).GetMatchers: changed from func() []StreamsMatcher to func() []StreamsPrivateLinkEndpointMatcher
- (_GroupAlertsConfig).GetMatchersOk: changed from func() (_[]StreamsMatcher, bool) to func() (*[]StreamsPrivateLinkEndpointMatcher, bool)
- (*GroupAlertsConfig).SetMatchers: changed from func([]StreamsMatcher) to func([]StreamsPrivateLinkEndpointMatcher)
- GroupAlertsConfig.Matchers: changed from *[]StreamsMatcher to *[]StreamsPrivateLinkEndpointMatcher
- NewStreamsMatcher: removed
- NewStreamsMatcherWithDefaults: removed
- StreamsMatcher: removed
